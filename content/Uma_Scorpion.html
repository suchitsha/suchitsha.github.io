UMA Scorpion

Technical Specifications & Details

Overview

This rugged mobile robot is designed for versatile surveillance, capable of operating in both day and night. It features an advanced weapon mount system and mine-trigger mechanism for detection and controlled activation at specific points. Its all-terrain capability ensures reliable performance, while the robust steering system provides precise control. The robot is fully customizable as per user requirements.
